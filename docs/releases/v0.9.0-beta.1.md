# sharpen-me v0.9.0-beta.1

Release candidate for a GitHub **Pre-release**, not Latest. Publication is pending review and approval. The repository is `soom-kang/sharpen-me`.

## Changes

- `sharpen-assess` separates unresolved reasoning from the volume of mechanical checks. A large rename alone does not justify higher reasoning effort.
- `sharpen-cold-review` distinguishes the caller's artifact from the skill instructions and separates document comprehension from code correctness evidence.
- `sharpen-review` and `sharpen-cold-review` distinguish ordinary change review from a review in an independent context, without requiring both skills to load.
- `sharpen-dedupe` permits a short result for a simple duplicate review instead of requiring a fixed report structure.
- Evaluation contract revision 4 retains paired command/result evidence with redaction and separate 8 KiB limits. Missing or truncated evidence cannot establish a PASS. Older evaluation contracts cannot resume or enter the new summary.

The eight public names, standalone installation units, invocation syntax, license and permission boundaries remain unchanged. No runtime dependency was added.

## Install after publication

```bash
npx skills add https://github.com/soom-kang/sharpen-me/tree/v0.9.0-beta.1 --skill '*' --agent codex claude-code
```

Choose **Project** scope. Codex uses `.agents/skills/`; Claude Code uses `.claude/skills/`. For old `rm-*` installations, save local edits and follow [the replacement steps](../rename.md#replace-an-existing-project-installation).

The existing local `v0.8.10-beta.1` tag retains the old names and is not part of this publication. No npm release or raw evaluation archive upload is included.
