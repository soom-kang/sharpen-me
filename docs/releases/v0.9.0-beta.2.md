# sharpen-me v0.9.0-beta.2

This GitHub **Pre-release** contains the skill changes evaluated in the [focused beta.2 report](../evaluation-v0.9.0-beta.2.ko.md). It is not marked Latest and is not published to npm.

## Changes since v0.9.0-beta.1

- `sharpen-clarify` checks consequential readings of bundled requests while resolving choices already settled by repository evidence.
- `sharpen-challenge` checks that a proposed test's observation supports its verdict and preserves independent blockers.
- `sharpen-assess` separates destructive authorization and demonstrated recovery from model advice, risk level, and suggested checks.
- `sharpen-cold-review` resolves supplied artifact paths, keeps document comprehension tied to its reader and purpose, and reports actual procedural commands and outcome meanings.
- `sharpen-brief` keeps a requested machine-readable output contract through the end of the response. `sharpen-refine` rereads the affected document in context after a documentation edit.
- The current evaluation configuration selects Codex `gpt-6-sol / medium` and Claude Code `claude-opus-5-5 / low`. Dated historical evaluation records keep their original model settings and results.

The eight skill names, standalone installation units, and permissions are unchanged. No runtime dependency was added.

## Evaluation and limits

The focused comparison covers 12 selected cases across six changed skills, with baseline and candidate runs on both providers. The **candidate passed all 24 selected slots**. The baseline has 21 PASS and 3 FAIL. These 48 final slot outcomes combine several explicitly authorized runs totaling 68 provider calls; they are not a single fresh 48-call pass. The observed outcomes and earlier failed or interrupted attempts remain separate in local archives.

| Provider | Before PASS / FAIL | Candidate PASS / FAIL |
| --- | ---: | ---: |
| Codex | 11 / 1 | 12 / 0 |
| Claude Code | 10 / 2 | 12 / 0 |

This small evaluation checks neither automatic skill selection nor all repetitions. `sharpen-review` and `sharpen-dedupe` were outside the selected set. The separate **576-call v3 gate remains unmet**: its recorded run stopped after 69 calls, and `evaluationPassed` and `releaseReady` remain `false`. Publishing this beta does not change those values or establish a general success rate.

## Local checks and installation

The release candidate is checked with `npm run verify`, `npm run test:install`, `npm run eval -- --dry-run`, `npm run test:docker`, and `git diff --check`. Verify CI must succeed for the exact release commit, and installation from the remote tag must pass before the GitHub Release is published.

```bash
npx skills add https://github.com/soom-kang/sharpen-me/tree/v0.9.0-beta.2 --skill '*' --agent codex claude-code
```

Choose **Project** scope. Codex installs to `.agents/skills/` and Claude Code to `.claude/skills/`. Save local edits before reinstalling; old `rm-*` names require the [replacement steps](../rename.md#replace-an-existing-project-installation). No raw evaluation archive is uploaded with this release.
