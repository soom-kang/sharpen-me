# v0.8.10-beta.1 — Historical first beta

This record covers the historical release under `refactor-me` and the original `rm-*` names. The tag and commands retain those names. At the time of renaming, the new names had not been behaviorally evaluated. See the [current name mapping and installation steps](../rename.md) and [current evaluation status](../evaluation.md).

Eight skills for planning, reviewing, and refactoring with Codex and Claude Code. This beta Pre-release does not certify stable behavior or passing evaluations for both agents.

## Included Skills

| Current name (see mapping above) | Purpose |
| --- | --- |
| `sharpen-clarify` | Clarify unresolved implementation decisions. |
| `sharpen-review` | Review changes for supported defects and compatibility risks. |
| `sharpen-challenge` | Check assumptions against evidence. |
| `sharpen-assess` | Assess change risk and execution requirements. |
| `sharpen-refine` | Refine code or documentation within an agreed scope. |
| `sharpen-cold-review` | Review an artifact in a separate context. |
| `sharpen-brief` | Rebuild project context for resumption or handoff. |
| `sharpen-dedupe` | Decide whether repeated code should share an implementation. |

Each Skill includes its instructions, Codex metadata, and MIT license. Skill content is unchanged from the prepared beta baseline; this release aligns version metadata and adds release and installation guidance.

## Install and invoke

Use Node.js 24.20.0 or later. From the project that will use the Skills:

```bash
npx skills add https://github.com/soom-kang/refactor-me/tree/v0.8.10-beta.1 --skill '*' --agent codex claude-code
```

1. Choose **Project** scope. Codex uses `.agents/skills/`; Claude Code uses `.claude/skills/`.
2. Send `$rm-review` in Codex or `/rm-review` in Claude Code, followed by the task and review scope. Use the same naming pattern for the other skills.

Invocation grants no permission to edit, deploy, or change model settings.

## Validation

Local release preparation passed on Node.js 24.20.0:

- Clean installation with `npm ci --ignore-scripts --offline --no-audit --no-fund` using cached dependencies.
- `npm run verify`: packaging, metadata, syntax, references, and all 74 regression tests passed.
- `npm run test:install`: whole-package and individual installs for both agents, copy and symlink modes, reinstall, removal, and unrelated Skill preservation passed.
- `npm run eval -- --dry-run`: 288 planned invocations enumerated with no provider calls.
- `npm run test:docker`: isolation checks passed with the required Node image.
- `git diff --check`: passed.

At that release, all 24 Skill files matched the frozen after snapshot from evaluation run `2026-09-09T05-50-58-256Z-v3` byte for byte.

Publication required the exact remote tag to pass the same installation suite. These checks cover packaging and installation compatibility, not agent behavior quality.

## Known limitations

- The Codex behavioral acceptance gate has not been met. The evaluated after version has 111 PASS, 12 FAIL, and 21 UNCLEAR results across 144 cases and repetitions.
- Claude behavioral evaluation remains deferred. Overall `releaseReady` remains false.
- Returned Codex model identity was unavailable in the recorded evaluation; identity evidence was limited to the explicit CLI argument.
- Historical baseline commit `09bb976` is absent from current repository history, so the public checkout alone cannot reproduce that before/after evaluation.
- No new provider evaluation, Skill behavior change, or npm publication is included in this release.
