# v0.8.10-beta.1 — First Beta

Eight Skills for planning, reviewing, and refactoring with Codex and Claude Code. This is a beta Pre-release, not a stable release or a claim that both agents have passed behavioral evaluation.

## Included Skills

| Skill | Purpose |
| --- | --- |
| `rm-scope` | Clarify unresolved implementation decisions. |
| `rm-review` | Review changes for supported defects and compatibility risks. |
| `rm-challenge` | Check assumptions against evidence. |
| `rm-assess` | Assess change risk and execution requirements. |
| `rm-refine` | Refine code or documentation within an agreed scope. |
| `rm-review-fresh` | Review an artifact in a separate context. |
| `rm-brief` | Rebuild project context for resumption or handoff. |
| `rm-dedup` | Decide whether repeated code should share an implementation. |

Each Skill includes its instructions, Codex metadata, and MIT license. Skill content is unchanged from the prepared beta baseline; this release aligns version metadata and adds release and installation guidance.

## Install and invoke

Use Node.js 24.20.0 or later. From the project that will use the Skills:

```bash
npx skills add https://github.com/soom-kang/refactor-me/tree/v0.8.10-beta.1 --skill '*' --agent codex claude-code
```

Choose Project scope. Codex uses `.agents/skills/`; Claude Code uses `.claude/skills/`. Use `$rm-review` in Codex or `/rm-review` in Claude Code, followed by the bounded task you want reviewed. The same naming pattern applies to the other Skills. Invocation does not grant permission to edit, deploy, or change model settings.

## Known limitations

- The Codex behavioral acceptance gate has not been met. The evaluated after version has 111 PASS, 12 FAIL, and 21 UNCLEAR results across 144 cases and repetitions.
- Claude behavioral evaluation remains deferred. Overall `releaseReady` remains false.
- Returned Codex model identity was unavailable in the recorded evaluation; identity evidence was limited to the explicit CLI argument.
- Historical baseline commit `09bb976` is absent from current repository history, so the public checkout alone cannot reproduce that before/after evaluation.
- No new provider evaluation, Skill behavior change, or npm publication is included in this release.
